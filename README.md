# Family Tree Management System 🌳

## About Project
A menu-driven C++ application that manages family relationships using a **General (N-ary) Tree** data structure.

## Features
- Create root ancestor
- Add family members
- Display family tree
- Search members
- Show ancestors, children and siblings
- Display generations using BFS
- Find relationships using LCA
- Remove members with descendants
- Display tree statistics

## Technologies Used
- Language: C++
- Data Structure: General Tree
- Concepts: Pointers, Recursion, DFS, BFS and Linked Lists
- STL Containers: Not Used

## How to Run

Compile:
```bash
g++ main.cpp -o family_tree
```

Run:
```bash
family_tree.exe
```
